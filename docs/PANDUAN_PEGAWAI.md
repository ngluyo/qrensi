# Panduan Pegawai QRensi

> Cara memakai aplikasi presensi dari HP Anda. Tidak perlu memasang aplikasi
> dari Play Store / App Store.

---

## 1. Masuk pertama kali

1. Buka alamat aplikasi yang diberikan admin (mis. `https://qrensi.vercel.app`).
2. Masukkan **email** dan **kata sandi sementara** dari admin.
   *Ketuk ikon 👁 untuk memastikan ketikan Anda benar.*
3. Sistem akan meminta Anda **membuat kata sandi baru** (minimal 8 karakter).
   Ini wajib — kata sandi dari admin hanya untuk sekali pakai.

## 2. Pasang ke layar utama (disarankan)

Agar terbuka cepat seperti aplikasi biasa:

- **Android (Chrome):** akan muncul tawaran "Pasang" di beranda — ketuk saja.
  Bila tidak muncul: menu ⋮ → **Tambahkan ke Layar Utama**.
- **iPhone (Safari):** ketuk tombol **Bagikan** ⬆️ → **Tambahkan ke Layar Utama**.

> Di iPhone, notifikasi hanya berfungsi bila aplikasi dipasang ke layar utama.

## 3. Lengkapi akun

Di beranda ada kartu **"Lengkapi akun Anda"**:
1. ✅ Ganti kata sandi
2. **Daftarkan wajah** — hubungi admin kepegawaian unit Anda (harus didampingi)
3. **Aktifkan notifikasi** — ketuk lalu izinkan

Kartu akan hilang sendiri setelah semua selesai.

---

## 4. Cara absen

Setiap sesi (masuk / istirahat / pulang):

1. Buka aplikasi → ketuk **Absen …** di beranda.
2. **Verifikasi wajah:** arahkan wajah ke kamera depan, lalu ikuti instruksi:
   - **Kedipkan mata 2×**
   - **Tolehkan kepala ke samping**
3. Setelah wajah cocok, kamera belakang aktif → **arahkan ke QR di layar kiosk** kantor.
4. Muncul tanda ✓ dan status Anda (tepat waktu / terlambat).

**Penting:** Anda harus berada **di depan kiosk** untuk memindai. Ini yang
membuktikan kehadiran Anda — tidak memakai GPS.

---

## 5. Melihat riwayat

**Riwayat** menampilkan kalender berwarna:

| Warna | Arti |
|---|---|
| 🟢 Hijau | Tepat waktu |
| 🟡 Kuning | Terlambat / pulang cepat |
| 🔵 Biru | Tidak terpantau di kantor |
| 🔴 Merah | Tidak hadir |

**Ketuk tanggal** untuk melihat rincian: jam absen Anda dibanding jadwalnya.
Di bawah kalender ada ringkasan bulan & **estimasi potongan**.

## 6. Mengajukan izin / sanggahan

**Profil → Izin & Sanggahan**:
1. Pilih jenis (izin, sakit, cuti, dinas luar, atau sanggahan presensi).
2. Isi tanggal & alasan, lampirkan surat bila ada (foto/PDF).
3. Kirim, lalu tunggu keputusan admin.

Bila **disetujui**, status hari itu otomatis diperbaiki dan tidak dihitung alpa.

## 7. Mengubah data & foto

**Profil → Edit profil**: ubah nomor HP, email kontak, alamat, dan **foto profil**.

Data kepegawaian (NIP, jabatan, unit, pola kerja) hanya bisa diubah admin. Bila
ada yang keliru, ajukan lewat menu **Izin & Sanggahan**.

---

## Masalah yang sering terjadi

| Masalah | Solusi |
|---|---|
| Kamera tidak menyala | Izinkan akses kamera. Chrome: ikon 🔒 di alamat → Izin situs → Kamera → Izinkan |
| "Wajah tidak terdeteksi" | Cari tempat lebih terang, lepas masker/topi/kacamata gelap, wajah di tengah lingkaran |
| "Wajah tidak cocok" | Coba sekali lagi; bila terus gagal, minta admin mengulang pendaftaran wajah |
| "Kode sudah dipakai" | QR sudah berganti — pindai lagi kode terbaru di layar kiosk |
| "Di luar jendela absensi" | Sesi belum dibuka atau sudah lewat. Cek jadwal di beranda |
| "Absen masuk pagi belum berhasil" | Sesi istirahat/pulang terkunci karena absen pagi gagal. Ajukan sanggahan |
| Tombol absen tidak muncul | Belum masuk jam sesi, atau Anda sudah absen untuk sesi itu |
| Lupa kata sandi | Hubungi admin kepegawaian untuk direset |

Butuh bantuan lain? Hubungi admin kepegawaian unit Anda.
